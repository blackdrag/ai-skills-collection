# ai-skills-collection

A version-controlled collection of reusable AI skills and writing guidance.

## Skills

- [Technical article writing](skills/technical-article-writing/SKILL.md) — narrative, tone, technical precision, examples, and AI-related discussion.
- [Karakun Developer Article](skills/karakun-developer-article/SKILL.md) — Karakun Developer Hub conventions built on top of the technical article writing style.

## Structure

The repository is intended to hold reusable guidance that can be consumed by ChatGPT skills, coding agents, or other AI tooling. The repository is the canonical, version-controlled form of the guidance; tool-specific skill wrappers can reference or incorporate it.
